# Trending Bazaar

Lightweight static e-commerce website using only HTML, CSS and Vanilla JavaScript.

## Files
- `index.html`
- `style.css`
- `script.js`
- `products.js`
- `assets/`

## Before publishing
1. In `script.js`, replace `BUSINESS_WHATSAPP` with the real WhatsApp number in international format, without `+`.
2. Replace demo products and ImgBB placeholder URLs in `products.js`.
3. Test cart -> checkout -> WhatsApp locally.
4. Push to GitHub and enable GitHub Pages.

No React, Node.js, Express, MongoDB, authentication, admin panel or payment gateway.
